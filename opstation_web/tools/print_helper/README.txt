Opstation Print Helper
======================
Lets Opstation print labels straight to your label printer (e.g. TSC TE200)
with one click - no print window.

Install (once, on the PC the printer is plugged into):
 1. Install the TSC printer driver; check the printer shows in Windows
    "Printers & scanners".
 2. Double-click OpstationPrint.exe.
    If Windows shows "Windows protected your PC": More info -> Run anyway.
    A message confirms "Installed and running". No window stays open - it runs
    quietly in the background and starts with Windows.
 3. Check: open http://127.0.0.1:9123 in Chrome - it should say
    "Opstation Print Helper is running".
 4. In Opstation, open a "Print labels" window. If Chrome asks to allow access
    to devices on your local network, press Allow. Then the gear icon ->
    pick your printer -> Test print.

Remove: double-click uninstall.bat.
