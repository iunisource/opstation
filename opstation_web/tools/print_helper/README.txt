Opstation Print Helper
======================
Lets Opstation print labels straight to your label printer (e.g. TSC TE200)
with one click - no print window.

Install (once, on the PC the printer is plugged into):
 1. Install the TSC printer driver and check the printer appears in Windows
    "Printers & scanners".
 2. Unzip this folder and double-click install.bat.
    If Windows shows "Windows protected your PC", click More info -> Run anyway.
 3. In Opstation, open any "Print labels" window, press the gear icon,
    pick your printer and press "Test print".

The helper runs quietly in the background, starts with Windows, and only
accepts print jobs from Opstation. Remove it any time with uninstall.bat.
